# Site content

The Astro pages read these JSON files directly. Add or edit records here, then
run `npm run build`.

- `projects.json` is generated from local software folders with `npm run portfolio:refresh`.
- Add client, operations, fitness, and media records to their matching files.
- Put selected images and video thumbnails in `public/uploads/`, then set the
  matching `image` field to `/uploads/filename.jpg`.
